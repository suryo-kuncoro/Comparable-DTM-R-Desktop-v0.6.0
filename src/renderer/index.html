Auto Ground: bila Class 2 ditemukan pada neighborhood GCP, hanya Class 2 digunakan. Jika tidak ada Class 2 dan cloud tampak ground-only/satu kelas, semua titik digunakan. Jika multi-class tanpa Class 2, proses dihentikan agar tidak mencampur vegetasi/objek lain.
